# Kiiri releases

Signed builds of [Kiiri](https://kiiri.app), the little cat that lives on your desktop.
This repo holds only release files and the auto-update feed. The source code is in
[kiiri-app/kiiri](https://github.com/kiiri-app/kiiri).

**Download:** [latest release](https://github.com/kiiri-app/kiiri-releases/releases/latest) · or [kiiri.app](https://kiiri.app)

| Platform | File |
| --- | --- |
| macOS (Apple silicon) | `Kiiri-<version>-arm64.dmg` |
| macOS (Intel) | `Kiiri-<version>-x64.dmg` |
| Windows | `Kiiri-Setup-<version>.exe` |
| Linux | `Kiiri-<version>.AppImage` |

The app updates itself from this repo. Bugs and ideas go to the
[main repo's issues](https://github.com/kiiri-app/kiiri/issues).
